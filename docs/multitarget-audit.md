# 同场景多目标数据可用性审查
2026-11-10

对CVOGL-SVI train/val/test共6239条记录按查询图和参考图文件SHA256分组：6239个不同图像对，没有相同两张图配不同目标真值的现成组合。
有952组重复查询图，跨所有划分共158对点击不同的候选。验证集内6对，实际只涉及2个地面场景，全部为环岛类别。统计单位是记录对，不是独立场景。

已目视检查val_candidates.jpg全部6对：第一场景的点击分别位于同一交通岛及其近旁路面，参考图显示相同道路结构的不同裁切/尺度；第二场景两次点击位于同一交通岛，参考图同样是不同裁切。没有确认出两个不同目标的有效真值。不能把这6对直接用于“正确目标切换率”，也不能据此断言所有158对均无效。

重要结果：记录ID不同、点击不同、框像素坐标不同，不等于目标实例不同。参考图裁切会改变框坐标。仅凭这些字段构造多目标试验会产生误导。这是数据审查结论，不是模型性能结果；本轮没有启动GPU评测。

下一步使用protocol.md固定的人工补标流程：先从验证集筛选10个有两个可跨视角确认目标的场景。各目标需要独立真值及复核。未复核标注只能用于探索性可视化，不能称为正式准确率。先建立场景清单，再考虑区域裁剪或实例特征增强，避免在缺乏正确真值时优化模型。
现有训练/测试候选可作为补充检查素材，但不混入验证集结果。原始数据不修改。

产物：scripts/audit_multitarget.py；summary.json、candidate_pairs.json（完全相同图像对候选为空）、query_candidates.json（158对）、val_candidates.jpg、protocol.md。图像与逐条标注仅在本地保留。
