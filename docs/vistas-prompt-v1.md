# 类别独立提示微调 v1 实验报告
日期：2026-11-11

## 结论
实验完整运行，只有8个已见类的4096个提示参数参与优化；检测网络权重及注册缓冲状态的SHA256前后完全相同，5个未见类的提示逐位不变。
3轮训练损失由8.2508降至6.9083、6.5030，但开发集总体AP下降。当前配置没有获得整体性能提升，不能据此推荐替代零样本基线，也不能把单次小样本结果解释为prompt tuning普遍无效。
局部有效证据：路灯AP提高，固定示例由“整根灯杆”转向“灯具”范围，说明独立提示能在冻结检测器时适配目标定义。

## 训练及评测
YOLO-World v2 Small，沿用公开权重yolov8s-worldv2.pt，SHA256 9b2c17ab6124a913e9b3a5c170617920d91b0f01111a8479da69f00e2cf27792。
Ultralytics8.3.93、PyTorch2.5.1+cu121。直接调用现有WorldModel和v8DetectionLoss；这是自定义的类别嵌入训练试验，不声称复现作者原始训练配方。
CLIP文本初始化，学习8×512向量；每次前向L2归一化；所有检测参数requires_grad=False，模型eval模式冻结BN状态，仍保留提示相关梯度。AdamW lr0.002、weight_decay0、梯度裁剪10、随机种子17，固定3轮，不按评测结果挑选checkpoint。
batch1、FP32、640×640等比缩放填充，分配器上限60%。训练仅输入8类提示，最终评测同时输入13类；未见提示沿用原始文本向量。没有更新共享适配器，也没有分割训练。
路灯文本为street light fixture，其余提示和完整顺序见manifest.json。微调前后使用同一提示初始化、相同输入处理和同一评测清单。

官方training内部选择：每个已见类按固定哈希排序最多选12张，合并为51张。排除包含任一未见目标类别或目标crowd标注的训练图片，避免把这些未见标注作为背景。不能保证没有未标注目标或预训练暴露。
开发样本：每类固定哈希选3张，合并为26张，与训练ID及图像SHA256不重叠。未检查近重复和街区独立性。未使用官方validation。
训练实例分布：路灯306、接线箱29、垃圾箱25、消防栓12、井盖53、雨水口34、电线杆226、店铺招牌89；未见类均为0。每类按图片选样仍造成明显实例不均衡。
全部77张所选图片的目标框由panoptic像素重新计算，使用min包含、max+1排除的边界；逐目标检查像素数与JSON面积一致。恢复正像素但原宽高为0的细目标，不再依赖旧“有效框”筛选。此次修复仅覆盖所选样本，不能说全数据集643条记录全部已复核。

评测采用pycocotools COCO bbox AP，IoU=.50:.95、101点召回、maxDets100。推理conf=.001、NMS=.7、最多300候选。bbox area用于尺寸口径，非mask area。开发选样排除了目标crowd；辅助类别不作为目标类。数据与样本已变化，不可与此前23图960输入固定阈值结果直接比较。

部分已见类别AP：
路灯0.04→3.13，雨水口0→4.17，电线杆1.11→2.79；
垃圾箱14.07→6.04，消防栓37.03→23.17，井盖5.35→3.73，店铺招牌1.15→0，接线箱仍为0。
未见类提示未变但输出指标可变化，因为提示也参与视觉特征调制及混合词表候选选择。未见宏平均基本不变只是本次证据，不是开放词汇能力完整保留的证明。
开发集中消防栓仅4个、邮箱和车架各3个，少量预测足以引起大幅AP变化；尚无多随机种子或置信区间结论。

## 诊断与资源
训练损失下降而开发AP下降，提示需要检查过拟合、样本不均衡、更新幅度与目标尺度；这些是待检验原因，不是已确定因果。

峰值allocated303.67MiB、reserved692MiB，计数重置于基线之后，涵盖训练及最终评测；无OOM。整卡占用另包含系统/驱动，不用此数替代。前向加NMS计时未含加载和预处理，也不用于速度优劣结论。

## 研究意义和下一步
研究A新增：可审计的类别提示训练路径、独立开发对照、框定义适配的局部证据，以及整体性能退化这一负结果。
尚未证明广泛的未见类别泛化、对Logo品牌识别的帮助或任何地理定位收益。研究B状态不变。
下一轮先扩大且平衡已见实例样本，保留一套新的独立开发检查样本；固定小范围学习率/更新轮次对照，检查原始文本嵌入约束是否能减少退化。一次改变一个主要因素，不直接堆叠切片和结构改造。
当前结果不支持立即扩大到正式全量验证。原始零样本和本轮全部prompt checkpoint均保留，不用退化版本覆盖原模型。
